# Tetris

Selaimessa toimiva Tetris yhtenä HTML-tiedostona.

Pelaa: https://reisga.github.io/tetris/

## Ohjaimet

| Näppäin | Toiminto |
|---|---|
| ← → | liiku |
| ↓ | pudota hitaasti |
| Välilyönti | pudota suoraan |
| ↑ / X | käännä myötäpäivään |
| Z | käännä vastapäivään |
| C / Shift | pito |
| P / Esc | tauko |

Puhelimella pelin alle tulee kosketusnapit.
